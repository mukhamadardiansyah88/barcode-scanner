# Neon Scanner 📷⚡

Web App Scanner **Barcode & QR Code** yang berdiri sendiri (Independent Web). Dibuat dengan HTML, CSS, dan JavaScript murni, serta menggunakan library `html5-qrcode` sebagai mesin pemindainya. 

Aplikasi ini di-hosting secara gratis melalui **GitHub Pages**.

## 🔗 Link Akses
[Klik di sini untuk membuka Neon Scanner](https://mukhamadardiansyah88.github.io/barcode-scanner/)

---

## ✨ Fitur Utama
- **Auto-Detect Kamera**: Otomatis menggunakan kamera belakang di HP, dan kamera bawaan di Laptop/PC tanpa perlu pilih-pilih.
- **Tema Neon Glow Premium**: Tampilan modern dengan animasi garis pemindai dan efek cahaya.
- **Deteksi Link Otomatis**: Jika hasil scan berupa URL (http/https), akan muncul tombol **"🔗 Kunjungi Link"**.
- **Scan Ulang (Reset)**: Tombol untuk kembali memindai tanpa perlu me-reload halaman.
- **Feedback Interaktif**: Suara *beep* nyaring dan getaran (khusus Android) saat scan berhasil.
- **Standalone**: Tidak terikat ke platform lain (bisa dipakai langsung dari browser).

---

## 🛠️ Cara Menggunakan
1. Buka link Neon Scanner (bisa lewat HP atau Laptop).
2. Izinkan browser untuk mengakses kamera.
3. Arahkan kamera ke Barcode atau QR Code.
4. Hasil scan akan muncul di layar.
5. Jika itu link, klik tombol **Kunjungi Link**. Jika ingin scan lagi, klik **Scan Lagi**.
